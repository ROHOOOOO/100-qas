## 项目上下文

用户希望制作一个名为 `100 Q&As` 的网页，用于和朋友玩“无意义100问”。用户提供了 `100 Q&As.docx`，其中包含 100 个问题。

已确认产品方向：

- 熟人私密使用。
- 不做注册账号。
- 每页 5 题。
- 提交后不可修改。
- 自己提交后才能查看其他人的答案。
- 结果页默认按题目查看大家答案。
- 第 23 题修正为“现在想吃什么?”。
