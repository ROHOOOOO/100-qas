# 每日开发记录

这个文件夹用于按日期记录项目开发过程。

命名规则：

```text
dev-days/YYYY-MM-DD/
```

每个日期文件夹包含：

- `README.md`：当天开发上下文和目标。
- `done.md`：当天已完成事项。
- `todo.md`：当天待办事项。
