# 账号与导出需求

## 背景

`Friends Games` 已支持真实多人房间。下一阶段需要解决两个问题：

- 同一玩家换手机或电脑后，可以通过登录同一账号找回自己的游戏记录。
- `100 Q&As` 结果可以导出为 PDF，方便保存或分享给参与者。

当前实现状态：前端和 SQL 已完成本地开发，本地自动化验收已通过；线上生效需要先在 Supabase SQL Editor 运行最新版 `supabase/schema.sql`，再发布前端并执行线上验收。

## 账号功能

第一版采用邮箱 + 密码注册登录。

- 登录方式：邮箱 + 密码。
- 手机号 + 密码：保留 UI 与数据设计空间，待短信服务配置后再启用。
- 用户可自行设定账号和密码。
- 登录后可查看“我的记录”。
- 新创建或新加入的房间，自动绑定到当前登录账号。
- 若用户此前在当前设备用匿名身份玩过，登录后可手动将这台设备里的匿名记录绑定到当前账号。
- 绑定后，用户在另一台设备登录同一账号，应能看到这些记录。

## 记录范围

### 100 Q&As

“我的记录”展示该账号参与过的房间：

- 房间码。
- 昵称。
- 题目数量。
- 是否已提交。
- 加入时间。
- 进入房间按钮。

已提交玩家重新进入房间后，可以查看结果页。

### Friends Tycoon

“我的记录”展示该账号参与过的房间：

- 房间码。
- 昵称。
- 房间状态。
- 现金或最终结果摘要。
- 是否房主。
- 进入房间按钮。

玩家中途换设备登录同一账号后，应能恢复自己的玩家身份。

## PDF 导出

第一版导出范围：

- 仅支持 `100 Q&As`。
- 仅从结果页导出。
- 只导出所有已提交玩家的答案。
- 未提交玩家的答案不导出。

交互方式：

- 结果页新增 `导出 PDF` 按钮。
- 点击后进入专门的导出版页面。
- 导出版页面提供 `打印 / 保存 PDF` 按钮。
- 用户通过浏览器打印功能选择“保存为 PDF”。

## 第一版不做

- 手机短信验证码正式登录。
- 找回密码的完整引导页面。
- 管理后台。
- 批量删除账号记录。
- PDF 自动上传或自动发送给朋友。
