# 账号与导出需求

## 背景

`Friends Games` 已支持线上多人房间。下一阶段重点是两件事：

- 玩家换手机或电脑后，可以通过登录同一朋友账号找回自己的 `100 Q&As` 和 `Friends Tycoon` 记录。
- `100 Q&As` 结果可以导出 PDF，目标是保存文件，不是打印纸质内容。

## 账号功能

第一版采用轻量朋友账号，不使用邮箱验证码或手机号短信。

- 登录方式：账号名 + 密码。
- 账号名规则：2-20 位，支持中文、英文、数字、下划线。
- 密码规则：至少 4 位，前端提醒不要使用重要账号密码。
- 账号规则必须在输入框为空时以灰色 placeholder 展示。
- 登录后可查看“我的记录”。
- 新创建或新加入的房间，自动绑定到当前登录账号。
- 用户此前在当前设备用匿名身份玩过，登录后可手动将本设备匿名记录绑定到当前账号。
- 绑定后，用户在另一台设备登录同一账号，应能看到这些记录并继续进入房间。

## 记录范围

### 100 Q&As

“我的记录”展示该账号参与过的房间：

- 房间码。
- 昵称。
- 题目数量。
- 是否已提交。
- 加入时间。
- 进入房间按钮。

已提交玩家重新进入房间后，可以查看结果页。未提交玩家仍只能继续答题。

### Friends Tycoon

“我的记录”展示该账号参与过的房间：

- 房间码。
- 昵称。
- 房间状态。
- 现金或最终结果摘要。
- 是否房主。
- 进入房间按钮。

玩家中途换设备登录同一账号后，应能恢复自己的玩家身份和可执行操作。

## PDF 导出

第一版导出范围：

- 仅支持 `100 Q&As`。
- 仅从结果页导出。
- 只导出所有已提交玩家的答案。
- 未提交玩家的答案不导出。

交互方式：

- 结果页提供 `导出 PDF` 按钮。
- 导出版页面提供 `下载 PDF` 主按钮，直接生成 PDF 文件。
- 导出版页面提供 `打开 PDF 预览`，用于旧手机无法直接下载时通过系统分享保存。
- 保留 `打印 / 系统保存` 作为兜底，不再把打印弹窗作为唯一导出方式。

## 第一版不做

- 邮箱验证、短信验证码。
- 找回密码完整流程。
- 管理后台。
- 批量删除账号记录。
- PDF 自动上传或自动发送给朋友。
