# 验收标准

## MVP 总体验

- 首页能作为 `Friends Games` 游戏大厅展示可选游戏。
- `100 Q&As` 与 `Friends Tycoon` 在导航和大厅中为并列关系。
- 用户能创建私密房间。
- 创建房间时能选择默认题库或自定义题库。
- 自定义题库识别到 1 到 100 题即可创建房间。
- 自定义题库为空或超过 100 题时，生成房间按钮仍可点击并给出清楚提示。
- 用户能复制邀请链接。
- 朋友能通过链接加入。
- 玩家能输入昵称开始答题。
- 每页展示 5 个问题，问题来自当前房间绑定的题库。
- 默认 100 题共 20 页；自定义题库页数按题量自动变化。
- 答案会保存草稿。
- 未答完当前题库的所有题目不能提交。
- 提交前有明确确认。
- 提交后不可修改。
- 未提交玩家不能查看其他人答案。
- 已提交玩家能按题目查看所有已提交玩家的答案。
- 不同房间可以展示不同题库。

## Friends Games 游戏大厅验收

- 打开首页显示 `Friends Games`。
- 首页提供 `100 Q&As` 和 `Friends Tycoon` 两个入口。
- 顶部导航可切换游戏大厅、`100 Q&As`、`Friends Tycoon`。
- `100 Q&As` 新房间链接使用 `#qa/room/:code`。
- 旧版 `#room/:code` 链接仍可打开 100 Q&As 房间。
- `Friends Tycoon` 入口展示已确认的第一版规则：2 到 6 人、32 格地图、最多 4 级升级、两种胜利条件、房主权限。

- `scripts/verify-static.mjs` 已通过，确认 Friends Games 标题、导航、Tycoon 入口和需求文档存在。
- `scripts/verify-browser.mjs` 已通过，覆盖本地游戏大厅、Friends Tycoon 规则页、100 Q&As 新路由和旧房间链接兼容。
- `scripts/verify-online.mjs` 已通过，确认 GitHub Pages 线上首页为 Friends Games，移动端大厅可见，线上 100 Q&As 双玩家流程仍可用。
- 验证结果：线上测试房间 `D51B22` 中 2 位玩家均提交 3 题，结果页显示 3 个题目卡和 6 条答案。

## Friends Tycoon MVP 验收

- 2 到 6 位玩家可进入同一房间。
- 只有房主可以开始游戏、重开游戏、解散房间。
- 少于 2 人时不能开始游戏。
- 地图有 32 个格子。
- 玩家按回合掷骰、移动和结算。
- 可购买无主地产。
- 可升级自己拥有的地产，最高 4 级。
- 踩到他人地产会支付租金。
- 现金低于 0 时立即出局。
- 玩家主动退出游戏后状态变为破产，其他玩家继续正常进行。
- 玩家刷新、关闭页面或闪退后，同一浏览器重新进入房间可以恢复原状态。
- 房主可选择最后幸存者或回合上限最富有者作为胜利条件。
- 聊天区与游戏记录分开显示。
- 游戏结束后清空聊天，保留最终结果和游戏记录。
- 游戏结束后可查看最终结果。

当前验证状态：

- `scripts/verify-static.mjs` 已通过，确认 Tycoon 路由、按钮、破产逻辑、4 级上限和 Supabase SQL 函数存在。
- `scripts/verify-browser.mjs` 已通过，覆盖本地 Friends Tycoon 创建房间、加入第二位玩家、房主开始、掷骰、结束回合、退出确认、退出即破产、刷新恢复、最终赢家和聊天结束清空。
- 线上 Tycoon 多人验收待用户在 Supabase SQL Editor 运行最新版 `supabase/schema.sql` 后执行。

- 直接打开 `index.html` 可运行。
- 创建房间流程可用。
- 加入房间和填写昵称流程可用。
- 答题页分页正确。

- 刷新后草稿仍存在。

- 提交后输入框不可编辑。
