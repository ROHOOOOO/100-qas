# 验收标准

## MVP 总体验

- 用户能创建私密房间。
- 创建房间时能选择默认题库或自定义题库。
- 自定义题库必须正好识别为 100 题才能创建房间。
- 用户能复制邀请链接。
- 朋友能通过链接加入。
- 玩家能输入昵称开始答题。
- 每页展示 5 个问题，问题来自当前房间绑定的题库。
- 共 20 页。
- 答案会保存草稿。
- 未答完 100 题不能提交。
- 提交前有明确确认。
- 提交后不可修改。
- 未提交玩家不能查看其他人答案。
- 已提交玩家能按题目查看所有已提交玩家的答案。
- 不同房间可以展示不同题库。

## 阶段 1 验收

- 直接打开 `index.html` 可运行。
- 创建房间流程可用。
- 加入房间和填写昵称流程可用。
- 答题页分页正确。
- 回到上一页时，已填写答案仍存在。
- 刷新后草稿仍存在。
- 未完成时提交按钮不可用或明确阻止提交。
- 完成后可以提交。
- 提交后输入框不可编辑。
- 结果页按题目展示答案。
- 自定义题库房间的答题页和结果页展示自定义问题。

当前验证状态：

- `scripts/verify-static.mjs` 已通过。
- `scripts/verify-browser.mjs` 已通过，覆盖完整 100 题提交闭环。

## 阶段 2 验收

- 能在本地模拟多个玩家。
- 不同玩家答案互不覆盖。
- 未提交玩家不能看结果。
- 已提交玩家可以看到其他已提交玩家答案。

当前验证状态：

- `scripts/verify-browser.mjs` 已覆盖两人本地模拟。
- 验证结果：2 人加入，1 人提交；未提交玩家停留在答题页，切换回已提交玩家后能查看结果。
- `scripts/verify-browser.mjs` 已覆盖上传自定义题库并创建房间。

## 阶段 4 验收

- 不同设备可加入同一房间。
- 数据能在线保存。
- 关闭页面后再次进入仍能继续。
- 提交锁定规则仍然有效。
- 邀请链接可正常使用。
- 自定义题库能保存到 Supabase，朋友打开房间后看到同一套自定义问题。

上线前置条件：

- Supabase 已运行最新版 `supabase/schema.sql`。
- `src/config.js` 已填入 Supabase Project URL 和 anon public key。
- GitHub Pages 已托管当前静态文件。

当前验证状态：

- `scripts/verify-online.mjs` 已通过。
- 验证结果：自定义题库线上房间 `25F8CE` 中 2 位玩家均提交 100 题，结果页显示 100 个题目卡、200 条答案，并确认第 23 题来自该房间自定义题库。
