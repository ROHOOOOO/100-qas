# 设计规范

## 设计气质

`Friends Games` 应该像一个轻松、亲密、适合朋友马上开玩的小游戏集合，而不是复杂游戏平台或企业工具。

`100 Q&As` 保持适合朋友慢慢填写的问答体验。`Friends Tycoon` 可以更有游戏感，但仍要清爽、可读、手机端友好。

关键词：

- 温柔
- 清爽
- 私密
- 轻量
- 有陪伴感
- 手机端友好

## 页面布局

- 第一屏直接提供主要操作，不做营销式落地页。
- 首页是“游戏大厅”，直接展示可选游戏。
- 顶部导航要清楚展示 `Friends Games`、`100 Q&As`、`Friends Tycoon`。
- 每个小游戏有独立入口，避免让用户误以为 `Friends Tycoon` 从属于 `100 Q&As`。
- 手机端优先设计。
- 答题页每屏只承载少量信息，避免压迫感。
- 每页固定 5 题，题目和输入框之间要有足够呼吸感。
- 结果页以问题为核心，先看到题目，再看到朋友们的答案。
- Friends Tycoon 桌面端使用左侧环形地图和右侧信息区；移动端使用全屏地图和底部浮窗。
- Friends Tycoon 房间第一屏要优先看到当前回合、可操作按钮、玩家状态和地图。
- Friends Tycoon 桌面宽屏时地图使用横向长方形棋盘，地点卡片要尽量放大，地点名称必须清楚可读。
- Friends Tycoon 移动端房间页地图应尽量占满屏幕，必要时允许轻微拖动查看大地图；地块可以是长方形，避免把操作区塞进棋盘中心。
- Friends Tycoon 移动端底部浮窗默认半收起，只露出当前回合和主按钮；展开后切换当前、动态、聊天、地块详情。
- Friends Tycoon 地图格子常驻信息保持简洁，只展示编号、地点名、归属或格子类型；买地、升级、过路费等明细按需展示。

## 颜色与视觉

- 避免单一大面积紫色、深蓝、棕橙、米色主题。
- 推荐使用清爽浅底，搭配少量柔和强调色。
- 按钮状态要明确：可点击、不可点击、提交危险确认。
- 不使用复杂装饰，不做过度拟物。
- Friends Tycoon 地图颜色保持克制：无主地产为浅灰色，事件格统一为冷灰色并使用虚线边框，玩家地产使用对应玩家的预设代表色。
- Friends Tycoon 玩家颜色限定为 6 个柔和预设色，开局前可选，避免自由取色导致撞色或视觉混乱。

## 交互规范

- 创建房间、复制链接、进入答题、提交答案都要有明确反馈。
- 游戏大厅选择游戏后，应进入对应游戏的独立页面。
- 创建房间页使用清晰的题库来源切换：默认题库 / 自定义题库。
- 自定义题库上传或粘贴后，要立即显示已识别题目数量。
- 自定义题库识别到 1 到 100 题时，生成房间按钮可用，并提示“可以生成房间”。
- 自定义题库为空或超过 100 题时，生成房间按钮仍可点击，并用提示说明问题。
- 草稿保存状态要轻提示，例如“已保存”。
- 提交前必须二次确认。
- 提交后所有输入框不可编辑。
- 未提交进入结果页时，要引导用户先完成答题。
- 本地原型可以展示房间进度和本地玩家切换入口，真实多人版本应收敛为参与者状态展示。
- Friends Tycoon 的聊天区和游戏记录必须分开，避免玩家聊天被系统日志刷掉。
- Friends Tycoon 的房主操作要清楚区分：开始游戏、重开游戏、解散房间、移除玩家。
- Friends Tycoon 的当前回合、当前玩家、可行动按钮要突出，其他玩家的不可用操作应禁用。
- Friends Tycoon 的退出、重开、解散、移除玩家都必须有页面内二次确认。
- Friends Tycoon 破产玩家可继续观看，但不能再行动或发送聊天。
- Friends Tycoon 地点详情在桌面端通过鼠标悬停或键盘聚焦展示，在手机端通过点击地点展示。
- Friends Tycoon 线上轮询不能频繁打断手机端操作；正在输入、刚点击按钮或关键游戏状态未变化时，应避免整页重绘地图。
- 地点详情至少包含买地价格、升级费用、当前过路费，以及 1 到 4 级过路费表。

## 文案规范

- 语气像朋友提醒，不像后台系统。
- 少用技术词。
- 避免长段说明。
- 重要规则要明确，例如“提交后不能修改”。

示例：

- `慢慢答，不着急。`
- `已保存`
- `还差 3 题就可以提交`
- `提交后就不能改啦，确认提交吗?`

## 移动端要求

- 按钮高度适合手指点击。
- 文本框高度足够输入短段回答。
- 顶部进度固定清晰。
- 长答案自动换行。
- 页面不出现横向滚动。

## 账号入口与恢复

- 登录与注册使用切换入口，只在注册页展示用户名和密保字段。
- 将登录账号与对外用户名的用途在字段旁说明；所有入口使用“所有功能共用账号”。
- 找回密码显示账号、密保、密码三个步骤，成功验证后才显示新密码表单。
- 校验错误显示在当前表单中，保留可重试的输入；密码和密保答案使用密码输入框。
- 注册、设置与恢复表单在手机上保持单列，不出现横向滚动。


## 密保中文输入与转盘折叠

- 密保答案默认显示文字，输入框旁提供至少 44px 点击高度的显示切换按钮，避免密码输入模式影响中文输入法。手机上输入框可缩小，按钮保持可见。
- 转盘面板标题整行可点击，也可通过键盘 Enter / Space 操作。使用原生 `details/summary` 提供展开状态语义，焦点边框清晰。
- “所有选项”标题显示数量；“抽取历史”标题保留全员可见说明；展开/收起文字和箭头随状态变化。
- 首次默认收起，控制独立。新增记录、同步及刷新保持用户选择，不抢占阅读位置。
- 新旋转从前次落点接续，落点避开扇区边界；尊重系统减少动态效果设置。

## Board Games

沿用 Friends Games 的浅色背景、深绿按钮和圆角卡片。木色棋盘，五子棋黑白立体棋子；中国象棋红黑字棋、楚河汉界、九宫线，自己的阵营位于下方。

棋盘上方显示轮次；象棋点击己方棋子后显示合法目标，标记最后落子和被将军的将帅。房间旁侧显示两席、电脑难度、准备状态、悔棋/求和/认输；重要操作使用页面内确认框。手机单列显示，棋盘保持比例。回放提供开局/上一步/自动播放/下一步/最后、滑杆与事件跳转；没有事件时禁用自动播放。

## 五种棋与房间聊天（2026-10-05）

- 棋类大厅五张卡片与现有色彩、留白和按钮样式一致，窄屏两列。
- 国际象棋可旋转为己方视角，选中棋子显示合法落点；升变明确弹出后/车/象/马选择。
- 飞行棋显示四架编号飞机、同色通道、路线与骰子；可动飞机有边框，也提供独立文字按钮。
- 跳棋展示 121 孔星形棋盘，草拟连跳路线后按“结束本步”提交，允许重新选择。
- 多人席位逐项显示准备、电脑难度与已获名次。完成者可看棋、回放并继续聊天。
- 聊天默认桌面展开、手机收起，记住个人房间偏好；显示发送人、时间及未读数。中文合成输入不因棋盘轮询而丢失；Enter 换行，Ctrl/⌘ + Enter 发送。
- 消息发送失败保留正文并提示重试；房间换局保留聊天。正文只作为文字显示，表情使用 Unicode。
