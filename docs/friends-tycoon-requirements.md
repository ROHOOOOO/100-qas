# Friends Tycoon 需求

## 产品定位

`Friends Tycoon` 是 `Friends Games` 中的文字版线上大富翁。它面向熟人朋友私密游玩，重点是轻量、好理解、能在线同房间同步，而不是复刻复杂桌游的全部细节。

## 已确认需求

- 游戏名称：`Friends Tycoon`。
- 所属产品：`Friends Games`。
- 与 `100 Q&As` 是并列小游戏，未来还可以继续添加其他小游戏。
- 每局游戏是一个私密房间。
- 第一版不做注册账号，玩家进入房间时填写昵称。
- 玩家上限 6 人。
- 至少 2 人即可由房主开始游戏。
- 第一版使用 32 个格子的地图。
- 地图主题可以先用“世界旅行”，格子内容包含不同国家城市、景点、机场、机会事件等。
- 支持简单地产升级，最多 4 级。
- 现金低于 0 时，玩家直接破产出局。
- 胜利条件由房主创建或开始游戏时选择：
  - 最后一位未破产玩家获胜。
  - 达到回合上限后，现金与资产总值最高者获胜。
- 页面分为游戏区和聊天区。
- 聊天区与游戏记录分开。
- 游戏记录保留关键行动，例如掷骰、移动、买地、升级、付租、破产、胜利。
- 单局结束后，长期只需要保留最终结果，例如胜利者、最终资金、资产情况。
- 聊天记录可以不长期保留，以节省存储空间。
- 玩家玩到一半关闭页面、刷新页面或浏览器闪退时，在同一浏览器重新进入房间链接应恢复原玩家状态。
- 玩家可以主动退出游戏；退出后该玩家状态变为破产，其他玩家继续正常游戏。
- 第一版需要房主权限：
  - 开始游戏。
  - 重开游戏。
  - 解散房间或退出游戏。

## 第一版建议玩法

- 起始现金：每位玩家 200,000。
- 每回合玩家点击掷骰，按点数前进。
- 经过起点获得固定奖励。
- 无主地产可购买。
- 踩到别人地产时支付租金。
- 拥有地产后可花钱升级，最高 4 级。
- 机会格触发随机事件，例如获得奖金、支付罚款、前进到指定地点。
- 机场或车站类格子用于快速移动或支付交通费。
- 税费格直接扣钱。
- 破产玩家不能继续行动，其资产可回到无主状态或由系统清算；第一版建议直接回到无主状态，规则更简单。
- 最后一位未破产玩家获胜时，已破产玩家不能因为现金或资产排序成为胜利者。

## 当前 MVP 已实现范围

- 创建 Friends Tycoon 房间。
- 通过房间码或邀请链接加入房间。
- 本地模式支持在同一浏览器中新增和切换玩家，方便开发验证。
- 房主可开始游戏、重开游戏、解散房间。
- 2 到 6 人限制。
- 32 格世界旅行地图。
- 轮流掷骰和移动。
- 经过起点获得现金。
- 奖金、税费、机会、地产格基础结算。
- 购买无主地产。
- 升级自己脚下的地产，最多 4 级。
- 支付他人地产租金。
- 现金低于 0 自动破产。
- 主动退出会二次确认，确认后按破产处理。
- 游戏结束后保留最终结果和游戏记录，清空聊天。
- 本地 `localStorage` 保存房间、玩家、地图、回合、聊天和记录，刷新后可恢复。
- 前端已接好 Supabase RPC 名称；线上可玩需要先在 Supabase SQL Editor 运行最新版 `supabase/schema.sql`。

## UI 方向

- 桌面端采用左右分区：左侧为游戏区，右侧为聊天区。
- 游戏区包含地图、当前玩家、玩家资产、回合控制、游戏记录。
- 聊天区只放朋友聊天，不混入系统游戏记录。
- 移动端优先保证可玩性：游戏区在上，聊天区可折叠或放到下方。
- 视觉可以比 `100 Q&As` 更活泼，但仍保持清爽、可读、适合手机。

## 后续待确认

- 房主是否可以踢出长时间离线的玩家。
- 地产价格、租金和升级成本的具体数值表。
- 回合上限可选范围，例如 20 / 30 / 40 回合。
- 是否需要私聊或表情反应。
- 游戏结束后是否提供复盘页。
