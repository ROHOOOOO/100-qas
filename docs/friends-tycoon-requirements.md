# Friends Tycoon 需求

## 产品定位

`Friends Tycoon` 是 `Friends Games` 中的文字版线上大富翁。它面向熟人朋友私密游玩，重点是轻量、好理解、能在线同房间同步，而不是复刻复杂桌游的全部细节。

## 已确认需求

- 游戏名称：`Friends Tycoon`。
- 所属产品：`Friends Games`。
- 与 `100 Q&As` 是并列小游戏，未来还可以继续添加其他小游戏。
- 每局游戏是一个私密房间。
- 支持朋友账号名 + 密码登录；登录同一账号后可在不同设备看到自己的大富翁记录。
- 玩家进入具体房间时仍填写昵称，昵称用于当局展示。
- 玩家上限 6 人。
- 至少 2 人即可由房主开始游戏。
- 第一版使用 32 个格子的地图。
- 地图主题可以先用“世界旅行”，格子内容包含不同国家城市、景点、机场、机会事件等。
- 支持简单地产升级，最多 4 级。
- 现金低于 0 时，玩家直接破产出局。
- 胜利条件由房主创建或开始游戏时选择：
  - 最后一位未破产玩家获胜。
  - 达到回合上限后，现金与资产总值最高者获胜。
- 页面分为游戏区和聊天区。
- 聊天区与游戏记录分开。
- 游戏记录保留关键行动，例如掷骰、移动、买地、升级、付租、破产、胜利。
- 单局结束后，长期只需要保留最终结果，例如胜利者、最终资金、资产情况。
- 聊天记录可以不长期保留，以节省存储空间。
- 玩家玩到一半关闭页面、刷新页面或浏览器闪退时，在同一浏览器重新进入房间链接应恢复原玩家状态。
- 玩家可以主动退出游戏；退出后该玩家状态变为破产，其他玩家继续正常游戏。
- 玩家破产、退出或被房主移除后，名下土地全部释放为无主地。
- 房主可以移除玩家；被移除玩家自动破产，如果正好轮到该玩家则自动进入下一位玩家。
- 房主可以退出游戏；退出后自动移交给下一位未破产玩家，原房主破产。如果没有可移交玩家，房间结束或关闭。
- 第一版需要房主权限：
  - 开始游戏。
  - 重开游戏。
  - 解散房间或退出游戏。
  - 移除玩家。

## 第一版建议玩法

- 起始现金：每位玩家 200,000。
- 每回合玩家点击掷骰，按点数前进；系统不会自动替玩家掷骰。
- 经过起点获得固定奖励。
- 无主地产可购买；掷骰后出现购买选择，8 秒未操作默认跳过。
- 踩到别人地产时支付租金。
- 走到自己的地产后可花钱升级，最高 4 级；每次落地最多升级一次。
- 本回合刚买下的地产不能立刻升级，必须下次再次走到该地块才能升级。
- 机会格触发随机事件，例如获得奖金、支付罚款、前进到指定地点。
- 机场或车站类格子用于快速移动或支付交通费。
- 税费格直接扣钱。
- 破产玩家不能继续行动，其资产可回到无主状态或由系统清算；第一版建议直接回到无主状态，规则更简单。
- 最后一位未破产玩家获胜时，已破产玩家不能因为现金或资产排序成为胜利者。

## 当前 MVP 已实现范围

- 创建 Friends Tycoon 房间。
- 通过房间码或邀请链接加入房间。
- 本地模式支持在同一浏览器中新增和切换玩家，方便开发验证。
- 房主可开始游戏、重开游戏、解散房间。
- 2 到 6 人限制。
- 32 格世界旅行地图。
- 轮流掷骰和移动。
- 经过起点获得现金。
- 奖金、税费、机会、地产格基础结算。
- 购买无主地产。
- 升级自己脚下的地产，最多 4 级。
- 支付他人地产租金。
- 现金低于 0 自动破产。
- 主动退出会二次确认，确认后按破产处理。
- 房主可移除玩家；移除后按破产处理。
- 掷骰后的买地/升级操作有 8 秒倒计时，超时默认跳过并自动换人。
- 买地或升级成功后立即进入下一位玩家，不再需要手动结束回合。
- 地图格子常驻信息已简化，具体买地价格、升级费用和过路费通过地点详情查看。
- 桌面端支持鼠标悬停地点查看详情；手机端支持点击地点查看底部详情浮层。
- 游戏结束后保留最终结果和游戏记录，清空聊天。
- 本地 `localStorage` 保存房间、玩家、地图、回合、聊天和记录，刷新后可恢复。
- 前端已接好 Supabase RPC 名称；线上可玩需要先在 Supabase SQL Editor 运行最新版 `supabase/schema.sql`。

## UI 方向

- 桌面端采用左右分区：左侧约 2/3 为环形地图与中心操作区，右侧约 1/3 为当前回合、游戏动态和聊天。
- 游戏区包含环形地图、当前玩家、当前位置说明、玩家资产、回合控制、游戏规则入口。
- 地产归属颜色与玩家颜色一致，破产、退出、被移除后土地回到无主颜色。
- 桌面端地图改为横向长方形棋盘，地点卡片不再强制正方形，方便看清中文地点名和玩家位置。
- 地点卡片常驻内容只保留编号、地点名、无主/归属/格子类型，避免价格、升级、租金全部堆在卡片上。
- 地点详情按需展示：买地价格、升级费用、当前过路费、1 到 4 级过路费。
- 手机端点击地点后，地点详情以底部浮层形式显示，避免被地图边缘裁切。
- 无主地产统一使用浅灰色；机会、税费、奖金、机场、休息等事件格统一使用同一种浅色。
- 玩家在开局前可从 6 个预设颜色中选择代表色，已被占用的颜色不可再选；玩家购买的地产使用该玩家代表色。
- 游戏动态以长条记录展示掷骰、移动、买地、升级、机会、租金、破产等事件。
- 聊天与游戏动态在右侧区域分开展示。
- 移动端优先展示地图，动态和聊天放入 Tab。
- 视觉可以比 `100 Q&As` 更活泼，但仍保持清爽、可读、适合手机。
